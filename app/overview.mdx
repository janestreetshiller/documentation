<h2 id="overview">What Ouros does</h2>

<p>Ouros is a macOS pop-up command surface. Find an app or a file, act on it, then return to what you were doing.</p><p>These guides cover installation, keyboard controls, permissions and routing. Read <a href="/app/not-built">What is not built yet</a> for features still unavailable.</p>

<h2 id="getting-started">Getting started</h2>

<ol className="docs-guide"><li><a href="/app/install">Install Ouros Bar</a> on a supported Mac.</li><li>Follow <a href="/app/first-action">Your first action</a> to open the bar and select an app or file.</li><li>Read <a href="/app/search-and-modes#prefixes">Prefix routing</a> before using a leading symbol.</li><li>If the result differs from what you expected, keep the attempted phrase and use <a href="/app/troubleshooting">Troubleshooting</a>.</li></ol><p>Opening a destination confirms routing. Check the result of the action separately.</p>
