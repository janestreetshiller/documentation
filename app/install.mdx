<h2 id="install">Install Ouros Bar</h2>

<p>Ouros Bar requires macOS 26 or later on an M-series Mac.</p><ol className="docs-guide"><li><a href="https://ouros.md/signup">Create an account</a> or <a href="https://ouros.md/login">sign in</a>.</li><li>Download Ouros Bar free from <a href="https://ouros.md/dashboard#/app">your account</a>.</li><li>Open the disk image and drag Ouros to Applications.</li><li>Launch Ouros from Applications. Enable permissions for the features you want to use.</li></ol><p>Read the <a href="/app/permissions">permission guide</a> before enabling microphone access or keyboard controls.</p>
