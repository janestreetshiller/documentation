<h2 id="first-action">Open, find and select</h2>

<p>Start with an app or file whose name you know.</p><ol className="docs-guide"><li><strong>Bring up the bar.</strong> Tap and release Right Option by itself. Once the bar is focused, another tap advances through the configured mode order.</li><li><strong>Type what you want.</strong> Search for an app or file. Read the matches before selecting one.</li><li><strong>Select the match.</strong> Check that the intended app or file opens.</li><li><strong>Return to your work.</strong> Right Control closes the bar. In Music, it can first return from a player or search view to the bar.</li></ol><p>Right Command controls dictation in the current app source. Use Right Option for opening and cycling the bar, and check these controls against your installed build.</p><p>If the bar opens only while Ouros is in front, check <a href="/app/permissions">Input Monitoring</a>. If another surface opens, check <a href="/app/search-and-modes#prefixes">the leading symbol</a> in your query.</p>
