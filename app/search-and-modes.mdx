<h2 id="search">Search and choose a mode</h2>

<p>App and file search with prioritization is built. If a file search finds nothing, check the folders selected in Search Settings.</p><p>The current source cycles through Files, Commands, Web, Chat, Music and Notes. Voice and Plugins have separate entry points. The configured order can differ.</p><dl className="docs-steps"><dt>Files</dt><dd>Find files, folders and applications.</dd><dt>Commands</dt><dd>Work with shell commands and local tools.</dd><dt>Web</dt><dd>Open the web search and browsing surface.</dd><dt>Chat</dt><dd>Use the selected model, subject to its connection and account access.</dd><dt>Music</dt><dd>Use the connected playback controls. The Spotify connection is partial.</dd><dt>Notes</dt><dd>Capture and work with notes.</dd></dl>
