# Ouros documentation

This repository is the Mintlify publishing source for Ouros app and Gateway documentation. `docs.json` defines the navigation and Ouros branding. Guide pages retain the existing website examples and availability boundaries.

## Preview and validation

Run `npx mint dev` from this repository to preview the documentation. Run `npx mint validate` for Mintlify validation and `node --test documentation.test.mjs` to check navigation and internal links.

## Updating guides

The initial guides are imported from `janestreetshiller/ouros-md-landing`. With that website checkout next to this repository, run `node scripts/sync-from-website.mjs`. To select another checkout, pass its path as the first argument.

The importer replaces guide MDX, the landing page, plan documentation and `docs.json`. Edit the website's `documentation/docs-app-guides.json`, `documentation/docs-gateway-guides.json`, or `site/pricing.mjs` before reimporting. Review the diff before committing. Brand SVGs are copied from the website and are not regenerated by the importer.

## Hosting and website integration

Connect `janestreetshiller/documentation` in the Mintlify dashboard. Set the documentation directory to the repository root. Use the branch configured in that dashboard for publishing; merging to a connected publishing branch may deploy automatically.

Confirm the assigned Mintlify hostname or verified custom domain before changing website routes. The website currently continues serving its existing `/docs` routes.

For a documentation subdomain, map website `/docs` to the hosted root and `/docs/<guide>` to `/<guide>`, retaining fragments and guide aliases. For same-domain `/docs` hosting, configure Mintlify's supported reverse proxy using the assigned project origin before replacing existing website rewrites. Verify deep links, search and Back on the hosted destination before switching traffic.

Browser examples using same-origin cookies must run on `https://ouros.md`, not on the documentation origin. Documentation hosting does not change authentication, billing or API access. The interactive recovery helper remains linked to its functioning website page.
