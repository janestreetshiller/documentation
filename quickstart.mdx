<h2 id="quickstart-mac">Use Ouros on your Mac</h2>

<p>Ouros Bar opens a compact bar for finding apps and files. Start here for the Mac app. For an API integration, continue to <a href="#first-request">the Gateway health check</a> below.</p> <ol className="docs-guide"><li><strong>Download.</strong> Ouros Bar requires macOS 26 or later on an M-series Mac. Open <a href="https://ouros.md/download">Download Ouros</a>, then create a free account or sign in with an available option. Your account opens on Download and install. Choose <strong>Download Ouros for Mac</strong> and wait for the disk image (a file ending in <code>.dmg</code>) to finish downloading.</li><li><strong>Install and open.</strong> Open the disk image from your browser’s downloads or Finder’s Downloads folder. Drag Ouros to Applications, wait for the copy to finish, then open Ouros from Applications. If macOS asks whether to open the app downloaded from the internet, choose <strong>Open</strong> for the Ouros copy you downloaded. If a different warning prevents opening, use <a href="/troubleshooting#troubleshooting">the installation checks</a>. See <a href="https://support.apple.com/en-us/102445">Apple’s first-open guidance</a>.</li><li><strong>Connect your account if prompted.</strong> If Ouros opens a sign-in page, keep the app running and finish in that browser page. Choose <strong>Connect Ouros</strong> if asked. If a device code is shown, match it with the code in Ouros before choosing <strong>Connect Ouros X</strong>. Return to the app and check that it confirms you are signed in. If it is still waiting, use <a href="/troubleshooting#recover-signin">the sign-in checks</a>.</li><li><strong>Find one app.</strong> With Ouros running, tap and release <strong>Right Option</strong> by itself: the Option key on the right of the space bar. Type the name of an app you know, such as Safari. Read the matches and select the intended app. Check that it opens. <strong>Right Control</strong> closes the bar. See <a href="/app/first-action">Your first action</a> for the controls.</li></ol> <p>If the bar opens only while Ouros is in front, go to <strong>System Settings → Privacy &amp; Security → Input Monitoring</strong> and enable Ouros. Follow any macOS request to quit and reopen it, then try from another app. You can turn this access off in the same place. See <a href="/app/permissions">Permissions</a> for other features.</p> <p>Browser sign-in alone does not confirm the app is connected. Mac permissions are separate from your account.</p>

<h2 id="first-request">1. Check service health</h2>

<p>Run this command in a terminal. The health endpoint requires no account or API key.</p>

```bash
curl --include --fail-with-body https://ouros.md/eve/v1/health
```

 <p>A successful response has HTTP status <code>200</code> and <code>Content-Type: application/json</code>.</p>

```json
{"ok":true,"service":"hvy-cloud-gateway"}
```

 <p>A health response confirms the Gateway is reachable. Check account access before creating a session.</p>

<h2 id="quickstart-account">2. Confirm account access</h2>

<p><a href="https://ouros.md/login">Sign in</a> and open the <a href="https://ouros.md/dashboard#/playground">playground</a>. To inspect access directly, run this JavaScript on the signed-in Ouros site. It reads <code>GET /hvy/v1/account</code> using your browser session.</p>

```javascript
// Run on the signed-in Ouros origin, for example in the playground.
const response = await fetch('/hvy/v1/account', {
  credentials: 'same-origin',
  cache: 'no-store',
});
const account = await response.json();
if (!response.ok) throw new Error(account.code ?? `HTTP ${response.status}`);
console.log(account.services);
```

 <p>The <code>services</code> object lists enabled services. Creating a chat session requires <code>services["cloud.chat.run"] === true</code>. If it is false, use the playground to review availability before sending a session request.</p>
